# Keil µVision Pure Black Dark Theme

A clean, high-contrast, pure black (`#000000`) theme configuration for **Keil MDK-ARM (µVision)** designed to reduce eye strain and improve code readability during embedded firmware development.

## 🎨 Color Palette & Syntax Highlights

- **Background:** Pure Black (`#000000`)
- **Default Text / Variables:** Light Gray (`#E0E0E0`)
- **Keywords (`int`, `for`, `void`, etc.):** Bold Cyan (`#00D7FF`)
- **User Types & Structs:** Bright Mint / Turquoise (`#00FFAA`)
- **Numbers & Literals:** Vibrant Gold (`#FFD700`)
- **Strings (`"..."`):** Bright Orange (`#FF8C00`)
- **Characters (`'...'`):** Neon Pink / Magenta (`#FF007F`)
- **Preprocessor Directives (`#include`, `#define`):** Bold Purple (`#D700FF`)
- **Comments (`//`, `/* */`):** Italic Bright Green (`#55FF55`)
- **Operators (`=`, `+`, `->`, `&`):** Pure White (`#FFFFFF`)
- **Active Line Highlight:** Charcoal (`#1A1A1A`)
- **Text Selection:** Steel Blue (`#264F78`)

1. **Close Keil µVision completely.**
2. Navigate to your Keil installation directory (typically `C:\Keil_v5\UV4\` or `C:\Keil\UV4\`).
3. **Backup** your existing configuration:
   - Rename `global.prop` to `global.prop.bak`.
